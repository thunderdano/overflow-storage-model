How each number is built. Storage months = whole months (rounded up) between ship date and install date. Site storage $ = storage months × site rate. Mobilization $ = one incremental "early" mobilization per shipment × the mob rate — a partial shipment is still one early trip, so ship method (Full / Partial) is informational, not a cost multiplier. Project total = site storage + mobilization.

What this doesn’t yet price (all of which favor overflow): expedited/rush freight when a truck is scrambled last-minute, quality risk on partial loads, and rent that keeps running when an install slips (Topanga +77d, OKC +133d, Raleigh +56d, Village Point +53d in current CAPEX data). Capacity: current finished-goods load is ~30 games' worth / ~1,500+ SKUs today and climbing into the October peak — size the target footage to that, and remember a space with a dock is worth more per foot than one without.
